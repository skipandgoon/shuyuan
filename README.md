# shuyuan · 书源仓库

个人书源归档。生成/修复的书源统一放对应目录，文件名 = 书源名：

- **legado/** — 开源阅读（Legado）书源 JSON
- **xiangse/** — 香色闺阁书源（.xbs 加密 + .json 明文对照）

## 导入方法

### Legado（开源阅读）
书源管理 → 右上角菜单 → 网络导入 → 粘贴 `legado/` 下 JSON 的 raw 链接

### 香色闺阁
站点 → 导入 → 粘贴 `xiangse/` 下 .xbs 的 raw 链接
