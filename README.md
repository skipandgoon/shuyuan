# shuyuan · 书源仓库

个人书源归档。文件名 = 书源名：

- **legado/** — 开源阅读（Legado）书源 JSON（每源一文件 + 全量合集）
- **xiangse/** — 香色闺阁书源（.xbs 每源一文件 + 全量合集）

## 导入链接

### Legado（开源阅读）
书源管理 → 右上角菜单 → 网络导入 → 粘贴链接（全量合集，346 源一次导入，含原始分组）：

https://raw.githubusercontent.com/skipandgoon/shuyuan/main/legado/legado-all.json

### 香色闺阁
站点 → 导入 → 粘贴链接（全量合集 .xbs）：

https://raw.githubusercontent.com/skipandgoon/shuyuan/main/xiangse/xiangse-all.xbs

> 合集由 GitHub Actions 自动维护：`legado/`、`xiangse/` 下单文件更新推送后，合集自动重新生成（raw 链接有几分钟 CDN 缓存延迟）。
