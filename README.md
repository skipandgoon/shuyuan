# shuyuan · 书源仓库

个人书源归档。文件名 = 书源名：

- **legado/** — 开源阅读（Legado）书源 JSON（每源一文件 + 全量合集）
- **xiangse/** — 香色闺阁书源（.xbs）

## 导入链接

### Legado（开源阅读）
书源管理 → 右上角菜单 → 网络导入 → 粘贴链接（全量合集，346 源一次导入）：

https://raw.githubusercontent.com/skipandgoon/shuyuan/main/legado/legado-all.json

如需单个源，可导入 `legado/` 下对应文件：`https://raw.githubusercontent.com/skipandgoon/shuyuan/main/legado/<文件名>.json`

### 香色闺阁
站点 → 导入 → 粘贴 .xbs 链接：

久久小说：https://raw.githubusercontent.com/skipandgoon/shuyuan/main/xiangse/jiujiu-xiaoshuo.xbs

沱书·文存：https://raw.githubusercontent.com/skipandgoon/shuyuan/main/xiangse/tuoshi-wencun.xbs
